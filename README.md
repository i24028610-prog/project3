按 Q 键退出时会自动保存 frames_YYYYMMDD_HHMMSS.csv 与 actions_YYYYMMDD_HHMMSS.csv 到 out_task1_real/

依赖环境为 Python 3.9+，需要安装 opencv-python、numpy、mss、pynput，运行方式为：python task1.py。
